PUBLISHING
  Upload everything (keeping the images/ folder next to the HTML files) to the
  web root of swapglobalventures.com/kpo_division/. File names match the old
  site, so existing links keep working. No build step or server code needed.

CONTACT FORM
  The form sends to info@swapglobalventures.com through FormSubmit.
  ONE-TIME STEP: after publishing, submit the form once yourself. FormSubmit
  emails a confirmation link to info@swapglobalventures.com; click it. Until
  then, submissions are not delivered.

MAP
  contact.html shows a Google Maps embed at Plus Code 535G+29 Nagpur
  (21.1575625, 79.0759375) with an OpenStreetMap fallback.

VISIT COUNTER
  images/counter.png is a static snapshot (1033), shown only on hover in the
  Contact footer, as on the old site. Replace its src with the live counter
  URL if you want a real count.

EXTERNAL RESOURCES USED
  Google Fonts (IBM Plex Sans and Mono), Leaflet 1.9.4 from cdnjs, Google Maps
  embed, OpenStreetMap tiles, FormSubmit.
